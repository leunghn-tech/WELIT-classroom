# 小一至小六中文課程遞進覆核

本次覆核以教師提供的兩個學習階段為基準：小一至小三先建立識字、句型、段落閱讀與基礎表達；小四至小六再逐步提升至主旨推論、描寫分析、說明與議論寫作，以及升中前的文言和綜合修訂。

| 年級 | 調整後首要路徑 | 重排理由 |
| --- | --- | --- |
| 小一 | 字詞 → 部首 → 標點 → 簡短故事 → 完整句子 | 保留啟蒙級的識字、句末語氣和生活句子基礎。 |
| 小二 | 童話／寓言 → 語境詞義 → 關聯詞 → 擴寫 → 日記／書信 | 先由看得見的故事資訊建立理解，再擴充句子及實用表達。 |
| 小三 | 說明文資料 → 段落重點 → 篇章類型 → 成語／修辭 → 六要素 → 段落／五感 | 把「找資料」擴展為「讀段落、辨篇章、組織篇章」。 |
| 小四 | 字詞／段意 → 語句與標點 → 句式 → 描寫 → 記敘 → 說明 → 實用文 | 先穩固分析工具，再進入人物、景物和有起伏的寫作。 |
| 小五 | 主旨／推論 → 複句 → 修辭 → 說明 → 記敘 → 進階實用文 → 審題 | 對應呈分試前的邏輯閱讀和說明表達需要。 |
| 小六 | 深層主旨 → 文言基礎 → 議論 → 抒情 → 實用文 → 修辭／改錯 | 由現代篇章的觀點閱讀銜接文言與升中前的綜合運用。 |

各單元原有的題目、答案、互動形式和題目數量均維持不變；本次只調整目錄和單元的教學順序、課程定位和教師可見的遞進說明。後續若要再擴充，優先項目是小三「同義詞／反義詞」的獨立題組，以及小四「中心思想與隱含線索」的獨立閱讀題組。
