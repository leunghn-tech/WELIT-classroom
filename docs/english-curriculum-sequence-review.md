# P1–P6 英文課程排序覆核

本次覆核以教師提供的 Key Stage 1 至 Key Stage 2 能力階梯為主軸，將現有題庫依「先語感與句型、後時態與段落、再文本結構與綜合應用」重新檢視。題庫不會因目錄調整而遺失；本文件同時記錄尚待日後建立的銜接單元，避免把尚未提供練習的內容誤列為已完成。

| 年級 | 已重整的現有學習路徑 | 後續可補充的核心銜接 |
|---|---|---|
| P1 | 字母與生活詞彙 → 代名詞 → to be／to have → 單複數 → 冠詞 → 位置介詞 → 朗讀與拼砌句子 | Initial／ending sounds、完整 26 字母語音 |
| P2 | 現在進行式 → 一般現在式 → Wh-Questions → can／can’t | Blends、digraphs、There is／There are、圖畫故事引導寫作 |
| P3 | 規則過去式 → 不規則動詞 → 代名詞 → 連接詞 → 數量詞 → 過去式朗讀／拼砌 | can／must 對照、段落主旨、30–40 字引導段落 |
| P4 | 修飾語 → 比較級 → 規則與建議 → 反身代名詞 → 進階連接詞 → 推論閱讀 | Simple Future、a few／a little／a lot of、日記／電郵／海報寫作 |
| P5 | 現在完成式 → 時間標記 → 被動語態與關係從句延展 → 長篇推論閱讀 | Past Continuous、Gerunds／to-infinitives、70–80 字 2–3 段寫作 |
| P6 | 條件句 → 條件句改寫 → 間接引語 → 間接引語改寫 → 非謂語動詞與片語動詞 → 證據式閱讀 | Passive Voice 整合、投訴信／建議書／辯論稿等 80–100 字實用寫作 |

> 現有 P5 被動語態與 P6 Type 2 條件句／非謂語動詞屬延展內容；保留它們可照顧能力較高的學生，但目錄會先清楚展示各年級的核心路徑。

排序檢核由 `scripts/auditEnglishSequence.mjs` 執行，確保每個英文單元仍有目錄映射，並維持覆核後的單元次序。
