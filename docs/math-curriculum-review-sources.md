# 數學課題覆核來源

本輪小一至小六數學題庫覆核以香港教育局的課程文件頁為主要參考。教育局列出《數學教育學習領域課程指引（小一至中六）（2017）》及《小學數學科學習內容（2017）》；本項目據此維持由具體數感、加減與量度，逐步過渡至乘除、分數、小數、代數、比率、圓形與統計的課程梯度。

| 用途 | 來源 |
|---|---|
| 小學數學課程及學習內容的官方入口 | [香港教育局：數學教育課程文件](https://www.edb.gov.hk/en/curriculum-development/kla/ma/curr/index2.html) |
| 小學數學課程資源與補充材料入口 | [香港教育局：小一至小六教學資源](https://www.edb.gov.hk/tc/curriculum-development/kla/ma/res/pri/addenda7.html) |

> 本文件只作項目內部課程對齊記錄；實際學校的教學進度、校本課程及評估安排仍應由任課教師決定。
